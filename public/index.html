Static Distribution

File Viewer Libraries

Контейнер раздаёт статические библиотеки для просмотра документов и файловых вложений. Предназначен для универсального просмотра файлов в 1С:Предприятие.

Доступные точки входа

/libs/ Набор отдельных JavaScript-библиотек для просмотра файлов. /ViewerJS/ Просмотр документов формата OpenDocumentFormat. /healthz Служебный endpoint для healthcheck контейнера и CI smoke-test.

Состав библиотек

  • pdf.min.js и pdf.worker.min.js для PDF
  • mammoth.browser.min.js для DOCX to HTML
  • jszip.min.js и docx-preview.min.js для DOCX preview
  • webodf.js для ODF-документов
  • ViewerJS как bundled viewer

Особенности сервера

  • Раздача через nginx в Docker-контейнере
  • Кэширование статических ассетов с долгим TTL
  • CORS-заголовки для библиотечных ресурсов
  • Отдельный healthcheck для локального запуска и GitHub Actions
