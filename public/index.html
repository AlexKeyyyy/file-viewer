Static Distribution

File Viewer Libraries

Контейнер раздаёт статические библиотеки для просмотра документов и файловых вложений в 1С:Предприятии. В сборку включены отдельные viewer-библиотеки, `ViewerJS` и веб-консоль `bsl_console` для редактирования и анализа BSL-кода.

Готово для Docker

Один production-ready образ на базе nginx:stable-alpine.

Статическая раздача

Ассеты, viewer-ресурсы и BSL-консоль доступны без отдельного backend.

Удобно для интеграции

Есть CORS-заголовки, healthcheck и предсказуемые URL для встраивания.

Доступные точки входа

/libs/ Набор отдельных JavaScript-библиотек для рендеринга файлов и документов. /ViewerJS/ Встроенный viewer для документов формата OpenDocument. /bsl_console/ Веб-консоль BSL с Monaco Editor и встроенными ресурсами для работы с кодом 1С. /healthz Служебный endpoint для контейнерного healthcheck и CI smoke-test.

Состав дистрибутива

  • pdf.min.js и pdf.worker.min.js для PDF.
  • mammoth.browser.min.js для преобразования DOCX в HTML.
  • jszip.min.js и docx-preview.min.js для DOCX preview.
  • webodf.js и ViewerJS для ODF-документов.
  • bsl_console с Monaco, BSL-grammar и вспомогательными модулями.

Технические особенности

  • Статическая раздача через nginx внутри Docker-контейнера.
  • Кэширование ассетов и gzip для типовых ресурсов.
  • CORS-заголовки для библиотек, viewer-ресурсов и BSL-консоли.
  • Отдельный URL для консоли: /bsl_console/ с корректным redirect со слэшем.

Этот контейнер можно использовать как готовый статический CDN-узел внутри дипломного проекта или как отдельный сервис инфраструктуры.
